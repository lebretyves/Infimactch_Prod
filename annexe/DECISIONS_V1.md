# Décisions produit retenues

Référence courante : [exigences](REQUIREMENTS_V1.md). État au 22 septembre 2026.

| Décision | Conséquence |
| --- | --- |
| Nom InfiMatch conservé | Renommage abandonné |
| Démonstration pédagogique Epitech, données métier fictives | Dans le scénario, les agences emploient et paient ; aucune activité réelle organisée par le projet |
| RIB facultatif | Proposition après première mission, jamais prérequis |
| Domicile et zone d'alertes séparés | Recherche temporaire sans modification automatique des alertes |
| Discord facultatif à la création | Configurer ou passer ; choix modifiable dans Notifications |
| RPPS réel | Attente et échec explicites, pas de validation fictive ; correspondance distincte de preuve d'identité |
| Candidature et décision humaine malgré un profil incomplet | Un blocage systématique serait trop restrictif : alerter sur les informations manquantes et les écarts avec la mission, permettre la candidature puis l’acceptation ou le refus ; conserver les contrôles d’affectation |
| Confirmation PDF | Pas de contrat complet signé ni de paie |
| MFA administrateur | QR de configuration livré ; enrôlement réel à vérifier |
| Epitech cité par le porteur ; aucun contact institutionnel fourni | Conserver le contact projet ; rôle effectif et identité juridique à préciser |
| Conservation des comptes et données de démonstration | Jusqu’à la fin de l’année scolaire en septembre 2027 puis suppression ; preuves anonymisées conservées pour le rendu |
| Quatre personnes, onze jours | Heures humaines et écarts à fournir par l'équipe |

Les automatisations retenues couvrent matching, confirmation et relance ; le sujet exige au moins deux scénarios nocode réalistes. Les recommandations admin complémentaires restent distinctes des exigences scolaires.

Décision précisée le 22 septembre 2026 (A04) : les alertes ne valent pas vérification des informations. Le critère RPPS du matching est distinct de la possibilité de candidater et de décider malgré un profil incomplet. Voir la [politique détaillée et ses preuves](quality/POLITIQUE_CANDIDATURE_AFFECTATION_2026-09-22.md).
