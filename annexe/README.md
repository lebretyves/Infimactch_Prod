## Organisation

| Dossier | Contenu et usage |
| --- | --- |
| references | Sujet et références de cadrage ; aucune instruction automatique |
| quality | Contrats opérationnels et campagnes datées ; lire leur portée |
| proofs | Résultats et mesures techniques, pas un état global courant |
| presentation | Support oral et scénario, à actualiser avant soutenance |
| rendu | Liste des livrables, recette et temps humains à compléter |
| n8n | Exports opérationnels documentés ; credentials séparés |
| diagrams | Illustrations d'architecture |

Les documents d'exploitation gardent leur contexte de validation. En cas de contradiction, vérifier le code et les exigences courantes ; ne pas transformer une ancienne preuve en promesse actuelle. Les conversations et anciens bilans ont été [archivés](ARCHIVES.md).
