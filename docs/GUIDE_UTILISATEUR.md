# Guide utilisateur — parcours actuels

> Actualisation du 24 septembre : voir [l’état courant](ETAT_COURANT.md) pour les nouveaux rappels préparés, les tests et la différence avec la production. Les preuves datées ci-dessous conservent leur portée.
Mise à jour documentaire : 22 septembre 2026. L'aide intégrée est définie dans [helpGuides.ts](../frontend/src/data/helpGuides.ts).

## Candidat

1. Créer le compte et renseigner les informations demandées. La vérification RPPS ne se confond pas avec la déclaration d'un diplôme.
2. Choisir de configurer Discord ou de passer cette étape : le compte est utilisable sans Discord. Les préférences restent modifiables dans Notifications.
3. Compléter Mon profil, puis Disponibilités et mobilité. Distinguer le domicile de la ville et du rayon de recherche enregistrés.
4. Ouvrir Rechercher une mission. Une recherche ponctuelle ne modifie pas les alertes ; enregistrer explicitement une nouvelle zone pour un changement durable.
5. Candidater à une mission interne, suivre la décision puis l'affectation. Pour une offre externe, poursuivre sur le site du fournisseur.
6. Consulter l'agenda et la confirmation PDF lorsqu'elle est prête. Un PDF InfiMatch ne constitue pas un contrat de travail signé.
7. Utiliser Documents et vérifications pour les justificatifs et la rubrique Vérification RPPS. Le RIB reste facultatif.

## Établissement ou agence

Configurer l'organisation et le site concerné, publier une mission avec ses vacations, examiner les candidatures et décider humainement de l'affectation. Suivre ensuite le PDF, les notifications et les éventuelles annulations. Une notification créée ne prouve pas la réception d'un email.

## Administrateur

Utiliser le portail séparé. À la première activation, l'invitation et la configuration de l'application d'authentification sont nécessaires. Le QR code est scanné dans cette application, qui fournit le code temporaire. Conserver les codes de récupération en privé. Ne jamais publier une invitation, un QR MFA ou un secret dans le rendu.

## Profil incomplet : comprendre les alertes

Vous pouvez envoyer une candidature même si certaines informations de votre profil manquent. Consultez les alertes : elles signalent les informations manquantes ou les écarts avec la mission. Compléter votre profil permet de mieux informer l’entreprise ou l’agence ; poursuivre ne marque pas ces informations comme vérifiées.

L’entreprise ou l’agence peut accepter ou refuser la candidature malgré ces alertes. Un profil incomplet ne doit pas provoquer un blocage systématique, trop restrictif. Les contrôles d’accès et d’affectation restent applicables : notamment, une autre mission déjà confirmée sur le même créneau empêche l’affectation, et les horaires précis doivent être confirmés.

Voir la [politique de candidature et d’affectation](quality/POLITIQUE_CANDIDATURE_AFFECTATION_2026-09-22.md).
